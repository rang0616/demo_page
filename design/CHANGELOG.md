형식:

```
## YYYY-MM-DD · 버전 · 제목
- 변경: 무엇을 바꿨는지
- 이유: 왜 바꿨는지
- ADR: 관련 ADR 번호
- 커밋: 해시 (커밋 후 기록, 알 수 없으면 `-`)
```

## 2026-10-15 · v0.1 구현 중 · 소스 폴더를 src/로, 배포를 Actions로 변경
- 변경: 배포 코드를 `docs/`에서 `src/`로 옮기고, Pages 배포를 GitHub Actions로 바꿉니다. 이어서 코드 리뷰 지적(폼 안전, 색 대비 토큰, 오류 분류, 도구 보강 등)을 반영합니다.
- 이유: 소스 코드를 `src/` 아래에 두고 싶다는 요청이 있었고, Actions 방식은 폴더 제한이 없기 때문입니다.
- ADR: 050(ADR-022 대체), 051
- 커밋: 8925355
