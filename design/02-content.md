# 02. 콘텐츠

상태: 초안 (편지 원문은 확정, 나머지 문구는 검토 필요)

## 콘텐츠 원칙

1. **편지 원문은 한 글자도 바꾸지 않습니다.** 휘님이 직접 쓴 글입니다. 맞춤법이나 말투를 다듬지 않습니다. (휘님이 직접 요청한 변경은 예외입니다. 맺음말의 영어 문장을 서명으로 바꾼 것, ADR-076. 암호문을 다시 만들기 전까지는 화면 코드가 대신 보여 줌)
2. **금액, 유효기간은 쓰지 않습니다.** (요청)
3. **개인정보를 더하지 않습니다.** 연락처, 계정, 상세 주소는 넣지 않습니다. 호칭(윰댕님, 휘, 윰댕)은 개인정보로 보지 않으며 안내 화면과 잠금 화면의 공개 HTML에 둡니다. `<title>`과 링크 미리보기(og)에는 이름을 넣지 않습니다. (ADR-021, ADR-030, ADR-057, ADR-059)
4. 말투 규칙은 ADR-029를 따릅니다. 요약: 휘님이 윰댕에게 말하는 화면 문구는 반말, 센터 정보는 존댓말입니다. 안내 화면 제목, 잠금 화면의 안내 문구, 선물 상자 안내와 편지 봉투 제목은 존댓말 예외입니다. (ADR-057, ADR-059, ADR-074)

## 잠금 질문

- 안내 문구 (두 줄, 존댓말 예외 ADR-059): **"신원을 확인하겠습니다." / "아래 질문에 답을 해주세요."**
- 질문: **"휘와 윰댕이 사귄 날은?"**
- 정답: 비공개 (`design/private/secrets.md` 참고)
- 허용 입력: 정규화 규칙을 따릅니다. (`06-decisions.md` ADR-025)
- 힌트는 없습니다.

## 편지 (원문)

편지 원문은 **비공개**입니다. 저장소에 올리지 않고 `design/private/secrets.md`에서만 관리합니다.

- 원문은 한 글자도 바꾸지 않습니다. (`06-decisions.md` ADR-007)
- 편지는 굵은 글씨 없이 평문으로 씁니다. 줄바꿈은 문단 단위입니다. 평문 포맷은 ADR-026을 따릅니다.
- 편지 문단 구성(공개 설계 기준): 호칭 → 고생에 대한 응원 → 진로 응원과 선물의 이유 → 회복과 운동에 대한 바람 → 사랑 고백 → 맺음말

- 주소: 서울특별시 서초구 강남대로 224
- 교통: 양재역 3·4번 출구 도보 3분
- 안내: 100% 사전 예약제 1:1 프라이빗 케어 센터
- 지도: 네이버 지도 링크 (검색어는 주소와 같음, ADR-012). 형식: `https://map.naver.com/p/search/` + 주소를 URL 인코딩한 값
- 이름과 주소 사용: 센터 측 확인 완료 (ADR-014)
- 소개 문구 3개는 삭제했습니다. (ADR-068. 원문은 Git 이력의 v1.1.0에 있습니다.)
- 센터 카드 맨 위에는 로고(`img/logo.jpg`, alt "리스파이어랩 로고")를 둡니다. (ADR-068)
