# 02. 콘텐츠

상태: 초안 (편지 원문은 확정, 나머지 문구는 검토 필요)

## 콘텐츠 원칙

1. **편지 원문은 한 글자도 바꾸지 않습니다.** 휘님이 직접 쓴 글입니다. 맞춤법이나 말투를 다듬지 않습니다.
2. **금액, 유효기간은 쓰지 않습니다.** (요청)
3. **개인정보를 더하지 않습니다.** 연락처, 계정, 상세 주소는 넣지 않습니다.
4. 말투 규칙은 ADR-029를 따릅니다. 요약: 휘님이 윰댕에게 말하는 화면 문구는 반말, 센터 정보는 존댓말입니다.

## 잠금 질문

- 질문: **"우리가 사귀기 시작한 날짜는?"**
- 정답: 비공개 (`design/private/secrets.md` 참고)
- 허용 입력: 정규화 규칙을 따릅니다. (`06-decisions.md` ADR-025)
- 힌트는 없습니다.

## 편지 (원문)

편지 원문은 **비공개**입니다. 저장소에 올리지 않고 `design/private/secrets.md`에서만 관리합니다.

- 원문은 한 글자도 바꾸지 않습니다. (`06-decisions.md` ADR-007)
- 편지는 굵은 글씨 없이 평문으로 씁니다. 줄바꿈은 문단 단위입니다. 평문 포맷은 ADR-026을 따릅니다.
- 편지 문단 구성(공개 설계 기준): 호칭 → 고생에 대한 응원 → 진로 응원과 선물의 이유 → 회복과 운동에 대한 바람 → 사랑 고백 → 맺음말

## 센터 정보

- 이름: 리스파이어랩 양재점
- 주소: 서울특별시 서초구 강남대로 224
- 교통: 양재역 3·4번 출구 도보 3분
- 안내: 100% 사전 예약제 1:1 프라이빗 케어 센터
- 지도: 네이버 지도 링크 (검색어는 주소와 같음, ADR-012). 형식: `https://map.naver.com/p/search/` + 주소를 URL 인코딩한 값
- 이름과 주소 사용: 센터 측 확인 완료 (ADR-014)
- 소개 문구 (데모 원문 그대로, ADR-017. 존댓말과 해요체가 섞인 것은 이 문구만의 예외입니다)
  1. **애쓰지 않고 누워서 받는 쉼**: 혼자서 힘겹게 하는 운동이 아니에요. 편안하게 호흡만 하면 물리치료사 출신 전문 스트레처가 온몸을 릴랙스해 줍니다.
  2. **악기 연주로 틀어진 자세 & 손·발 통증 케어**: 어렸을 때부터 틀어진 체형과 고질적인 통증, 일하느라 뭉쳤던 몸을 체계적인 1:1 분석을 통해 시원하게 풀어드립니다.
  3. **프라이빗 1:1 맞춤 케어 20회**: 오직 윰댕의 컨디션에 맞춰 100% 예약제로 진행되는 프라이빗한 힐링 리커버리 시간이에요.
