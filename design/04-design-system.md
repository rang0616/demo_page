# 04. 디자인 시스템

상태: 초안 (색과 글꼴은 제안입니다. 같이 보고 확정합니다.)

## 방향

**아기자기하고 귀엽고, 정돈된 느낌.** 데모는 요소가 너무 많고 강한 금색 그라데이션, 배지, 이모지가 한꺼번에 나와서 쇼핑몰(테무) 같았습니다. 새 디자인은 다음을 지킵니다.

- **한 화면에 주인공은 하나.** 잠금 화면은 질문 하나, 공개 화면은 섹션 하나씩.
- **둥글고 부드러운 모양.** 손그림 같은 장식을 소량 씁니다.
- **색은 적게.** 기본 배경 하나, 포인트 색 하나, 글자 색 두 개.
- **장식은 의미 있을 때만.** 하트나 별은 페이지당 몇 개로 제한합니다.

## 색상 (제안)

| 역할 | 제안 값 | 설명 |
|------|---------|------|
| 배경 | `#FFF8F4` | 따뜻한 크림 핑크 |
| 카드 | `#FFFFFF` | 흰 카드 |
| 포인트 | `#F4A7A7` | 연한 로즈 핑크 |
| 보조 포인트 | `#BFD8C8` | 연한 민트 (소량) |
| 본문 글자 | `#4A3F3F` | 따뜻한 짙은 갈색 |
| 흐린 글자 | `#9C8C8C` | 보조 정보 |

- 골드는 빼고 핑크 계열로 전환합니다. 최종 색은 `07-open-questions.md` Q6에서 확정합니다.

## 글꼴

- 본문: **Pretendard** (둥글고 깔끔한 한국어 고딕)
- 편지: 손글씨 느낌이 나는 한국어 웹폰트 1종 후보 (예: 나눔손글씨, 여기어때 잘난체 등). 편지 원문은 가독성이 중요하므로 크기와 행간을 넉넉히 둡니다. 최종 선택은 Q6.
- 영문 장식 라벨은 한두 곳에만 씁니다.

## 모양과 간격

- 카드 모서리는 크게(20px 안팎) 둥글게 합니다.
- 버튼과 입력창은 pill 모양입니다.
- 그림자는 얇고 부드럽게 한 단계만 씁니다.
- 좌우 여백은 최소 16px, 모바일 기준으로 설계합니다.

## 움직임

- 선물 상자는 살짝 떠 있는 움직임 하나만 둡니다.
- 열림 연출은 1초 안쪽으로 끝냅니다.
- `prefers-reduced-motion`이 켜져 있으면 움직임을 줄입니다.

## 이모지

- 이모지는 제목이나 마무리 문장 끝에만 씁니다. 하트 정도로 제한합니다.
