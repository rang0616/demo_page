# 01. 경험 흐름

상태: 초안

페이지는 두 개의 씬(Scene)과 하나의 모달로 구성됩니다. 씬 전환은 한 번만 일어나며 되돌아가지 않습니다.

## 흐름도

```
[SCENE 1 티저]
  선물 상자(떠다니는 중) ──탭──▶ 상자 열림 애니메이션
                                  + 효과음 + 콘페티 + BGM 자동 시작
                                  + 0.65초 뒤 티저 숨김
                                          │
                                          ▼
[SCENE 2 메인 공개]
  서프라이즈 헤더
  ① 골든 바우처 카드
  ② 편지 카드 (기본 펼침, 접기/펼치기)
  ③ 패시브 스트레칭 소개 (3가지 혜택)
  ④ 센터 위치 (네이버/카카오 지도, 주소 복사)
  ⑤ CTA "첫 번째 예약 날짜 고르기"
                                          │
                                          ▼
[예약 모달] (바텀 시트)
  달력 → 시간대 선택 → 요약 → "오빠한테 예약 날짜 보내기"
  → 메시지 클립보드 복사 → 안내 alert → 모달 닫힘
```

## 상태 규칙

| 상태 | 조건 | 화면 |
|------|------|------|
| 닫힘 (초기) | 페이지 로드 | 티저만 보임 |
| 열림 | 상자 탭 (1회만 동작) | 메인 공개 |
| 공개 후 | 스크롤 | 메인 콘텐츠 |

- 상자 탭은 **한 번만** 동작합니다. 다시 탭해도 아무 일도 일어나지 않습니다.
- BGM은 상자를 열 때 자동으로 켜지고, 우측 상단 버튼으로 끄고 켤 수 있습니다.
- 편지는 기본 펼침 상태로 시작합니다.

## 동선 원칙

1. **첫 화면에서 설명하지 않습니다.** 상자 하나와 짧은 안내 문구만 둡니다.
2. **바우처가 먼저, 설명은 나중에** 나옵니다. 선물을 먼저 보여 주고 이유(편지, 혜택)를 이어 줍니다.
3. **예약은 마지막 단계**입니다. 메인 화면 하단 CTA에서 한 번 들어가며, 날짜를 고르지 않으면 보낼 수 없습니다.
4. 모든 행동은 한 손가락 탭으로 끝나야 합니다. 텍스트 입력은 없습니다.

## 오류·예외 흐름

- 날짜를 고르지 않고 보내기를 누르면 alert로 안내하고 모달을 닫지 않습니다.
- 클립보드 API를 쓸 수 없는 환경에서는 복사가 실패할 수 있습니다. 현재 구현은 실패를 알리지 않으므로 `07-open-questions.md`에 기록해 둡니다.
- 오디오 컨텍스트는 사용자 탭 이후에만 시작합니다. 자동 재생 차단이 있어도 페이지는 정상 동작해야 합니다.
