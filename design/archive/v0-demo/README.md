# design/ — 프로젝트 설계 문서 (SoT)

이 디렉토리는 gift_insp_lab의 **단일 진실 공급원(Single Source of Truth)** 입니다.
무엇을, 왜, 어떤 규칙으로 만들지는 모두 여기에 md로 적습니다. 코드는 이 문서의 결과물일 뿐입니다.

> 헌법 조항(CLAUDE.md 0장)에 따라 코드 변경은 이 디렉토리의 문서를 따릅니다.

## 작성 규칙

1. **문서가 먼저, 코드가 나중입니다.** 새 기능이나 변경은 해당 문서를 먼저 고친 뒤 구현합니다.
2. **문서와 코드가 어긋나면 문서가 맞습니다.** 코드를 고쳐서 문서에 맞추거나, 문서를 고친다는 결정을 `06-decisions.md`에 남기고 나서 고칩니다. 조용히 어긋나게 두지 않습니다.
3. **결정은 기록합니다.** 설계를 바꿀 때는 `06-decisions.md`에 날짜, 배경, 결정, 영향을 한 항목으로 추가합니다.
4. **모르는 것은 `07-open-questions.md`에 적습니다.** 추측으로 채우지 않습니다.
5. 각 문서 상단에 `상태`(초안 / 확정 / 폐기)를 표시합니다.
