# 06. 결정 기록 (ADR)

상태: 진행 중

설계를 바꾸는 결정은 아래 형식으로 **가장 아래에 추가**합니다. 기존 항목은 지우지 않고, 바뀌면 `상태: 대체됨 (ADR-XXX)`로 표시합니다.

```
## ADR-XXX. 제목
- 날짜: YYYY-MM-DD
- 상태: 확정 / 대체됨 (ADR-YYY)
- 배경: 왜 결정이 필요했는지
- 결정: 무엇을 하기로 했는지
- 영향: 바뀌는 문서와 코드 위치
```

---

## ADR-001. 설계 문서를 `design/`에 두고 SoT로 삼는다
- 날짜: 2026-10-15
- 상태: 확정
- 배경: 모든 개발을 Claude Code로 진행하므로, 의도와 규칙이 대화 기록이 아니라 파일로 남아야 합니다.
- 결정: `design/` 디렉토리의 md 문서가 단일 진실 공급원입니다. 코드는 문서를 따르며, 문서와 코드가 어긋나면 문서가 기준입니다.
- 영향: `CLAUDE.md` 0장(헌법), `design/README.md`

## ADR-002. 빌드 없이 단일 `index.html`을 유지한다
- 날짜: 2026-10-15
- 상태: 확정
- 배경: 개인 선물 페이지라 규모가 작고, 공유와 배포를 단순하게 하고 싶습니다.
- 결정: 프레임워크와 번들러를 쓰지 않고, HTML·CSS·JS를 `index.html`에 둡니다.
- 영향: `05-architecture.md` 단일 파일 원칙
