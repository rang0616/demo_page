# 02. 콘텐츠

상태: 초안

## 콘텐츠 정책 (헌법 수준)

1. **개인 콘텐츠는 사용자의 명시적 요청 없이 바꾸지 않습니다.** 편지 본문, 호칭, 말투(반말 편지체), 바우처 정보가 여기에 해당합니다.
2. **공개 페이지에 개인정보를 추가하지 않습니다.** 실명, 연락처, 계정, 주소 외 상세 개인 정보는 넣지 않습니다. 센터 주소는 사업장 정보이므로 허용합니다.
3. 화면 문구의 말투는 **오빠 → 윰댕**의 친근한 반말을 기본으로 합니다. 센터 안내 문구만 존댓말을 씁니다.

## 바우처 데이터

| 항목 | 값 |
|------|-----|
| 수신자 | 윰댕 ❤️ |
| 사유 | 퇴사 & 대학원 & 생일 선물 ✨ |
| 센터 | 리스파이어랩 양재점 |
| 상품 | 1:1 맞춤 컨디셔닝 (20회) |
| 상품명 | 패시브 스트레칭 20회 회원권 |
| 영문 라벨 | VIP Recovery Membership / SPECIAL 20 SESSIONS |

## 편지

- 호칭: "사랑하는 윰댕에게 ❤️"
- 구성: 응원(그동안 고생) → 이유(악기 연주로 틀어진 몸, 주기적 통증을 보며 준비한 선물) → 바람(통증 완화, 운동 재미) → 마무리("내가 진짜 엄청 사랑한당 알쥐? ❤️")
- 맺음말: "With all my love & support."
- 본문 문장은 `index.html`의 `.letter-body`가 원본입니다. 문장을 바꾸려면 **이 문서를 먼저 고칩니다.**

## 소개 문구 (패시브 스트레칭 3가지 혜택)

1. 애쓰지 않고 누워서 받는 쉼 — 물리치료사 출신 스트레처
2. 악기 연주로 틀어진 자세와 손·발 통증 케어 — 1:1 분석
3. 프라이빗 1:1 맞춤 케어 20회 — 100% 예약제

## 센터 정보

- 이름: 리스파이어랩 양재점
- 주소: 서울특별시 서초구 강남대로 224
- 교통: 양재역 3·4번 출구 도보 3분
- 안내: 100% 사전 예약제 1:1 프라이빗 케어 센터
- 지도 링크: 네이버 지도, 카카오맵 검색 링크 (검색어는 주소와 같습니다)
