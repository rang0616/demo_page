# 00. 개요

상태: 초안

## 목적

윰댕(수신자)에게 **"선물 상자를 열면 특별한 바우처와 편지가 나타나는"** 경험을 모바일 웹 한 페이지로 전달합니다. 선물은 리스파이어랩 양재점 패시브 스트레칭 20회 회원권입니다.

## 대상

- **수신자**: 윰댕. 주로 휴대폰으로 카카오톡 링크를 통해 열어 봅니다.
- **발신자**: 오빠(개발·운영). 페이지를 만들고 예약 요청 메시지를 받습니다.

## 범위

포함:
- 선물 상자 티저 → 바우처 공개 → 편지 → 센터 안내 → 예약 날짜 요청
- 배경음악 토글, 효과음, 콘페티 연출
- GitHub Pages 정적 배포

제외 (현재 버전):
- 서버, 데이터베이스, 로그인
- 실제 예약 시스템 연동 (예약은 메시지 복사로 끝납니다)
- 다국어 (한국어 전용)
- 여러 수신자 관리

## 성공 기준

1. 휴대폰(390px 폭)에서 가로 스크롤 없이 전 과정이 끝까지 동작합니다.
2. 상자를 열면 3초 안에 콘페티와 함께 바우처가 보입니다.
3. 예약 요청 메시지가 클립보드에 복사되고, 카카오톡에 바로 붙여넣을 수 있습니다.
4. 저장소 파일 수가 늘지 않습니다. 단일 `index.html` 구조를 유지합니다.
