# 03. 예약 요청 규칙

상태: 초안

이 기능은 실제 예약 시스템이 아니라 **날짜 요청 메시지를 만드는 도구**입니다. 최종 예약은 오빠가 센터와 직접 잡습니다.

## 입력

| 항목 | 규칙 |
|------|------|
| 날짜 | 미니 캘린더에서 하나를 고릅니다. **오늘 이전 날짜는 선택할 수 없습니다.** |
| 시간대 | 4개 중 하나. 기본값은 오전입니다. |
| 월 이동 | 이전·다음 달 버튼. 달 이동은 제한하지 않습니다. |

### 시간대 목록

| 표시 | 저장 값 |
|------|---------|
| ☀️ 오전 (11:00) | `☀️ 오전 (11:00 ~ 13:00)` |
| 🌤️ 오후 (14:00) | `🌤️ 오후 2시 (14:00)` |
| ☕ 오후 (16:00) | `☕ 오후 4시 (16:00)` |
| 🌙 저녁 (18:00) | `🌙 저녁 6시 (18:00)` |

## 출력 메시지 형식

```
오빠! 나 리스파이어랩 양재점 첫 방문 예약 {M}월 {D}일 ({요일}) {시간대} 로 갈래! 양재점에 맞춰서 예약 잡아줘 💕
```

예: `오빠! 나 리스파이어랩 양재점 첫 방문 예약 10월 20일 (화) ☀️ 오전 (11:00 ~ 13:00) 로 갈래! 양재점에 맞춰서 예약 잡아줘 💕`

## 동작 규칙

1. 날짜가 없으면 보내기를 막고 "먼저 날짜를 골라 달라"는 안내를 띄웁니다.
2. 보내기를 누르면 메시지를 클립보드에 복사하고, 복사된 메시지를 보여 주는 안내를 띄운 뒤 모달을 닫습니다.
3. 메시지는 **카카오톡에 붙여넣어 전송하는 것**이 목적입니다. 페이지가 직접 서버로 보내지 않습니다.
4. 요약 문구는 날짜와 시간대를 고를 때마다 바로 갱신합니다.

## 변경 원칙

- 시간대를 추가하거나 바꾸면 **이 문서의 목록과 `index.html`의 칩 3곳(표시·onclick 값·`selectedTime` 기본값)을 함께 고칩니다.**
- 메시지 문장 형식을 바꾸면 이 문서의 형식을 먼저 고칩니다.
- 예약 가능 여부(요일별 휴무 등)는 현재 반영하지 않습니다. 필요하면 `07-open-questions.md`에서 결정합니다.
