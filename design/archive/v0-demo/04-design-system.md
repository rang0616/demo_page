# 04. 디자인 시스템

상태: 초안

톤: **따뜻한 골드와 크림, 로즈 포인트.** 고급스럽지만 무겁지 않고, 선물을 여는 설렘을 주는 분위기입니다.

## 색상 토큰

현재 `index.html`의 `:root` CSS 변수가 원본입니다. 값을 바꾸면 이 표도 같이 고칩니다.

| 토큰 | 값 | 용도 |
|------|-----|------|
| `--bg-cream` | `#F8F6F0` | 메인 배경 |
| `--bg-warm` | `#F4EFE6` | 보조 배경 |
| `--bg-card` | `#FFFFFF` | 카드 배경 |
| `--text-main` | `#242220` | 본문 |
| `--text-sub` | `#635C54` | 보조 텍스트 |
| `--text-muted` | `#999084` | 흐린 텍스트 (푸터 등) |
| `--gold-primary` | `#C5A059` | 강조, 테두리 |
| `--gold-light` | `#EFE4CF` | 옅은 골드 면 |
| `--gold-dark` | `#967433` | 골드 텍스트, 아이콘 |
| `--gold-gradient` | `135deg #D8B772 → #B89249` | 리본, 버튼 |
| `--rose-accent` | `#D96B6B` | 포인트, 하트 |
| `--rose-light` | `#FDF3F3` | 로즈 면 |

- 상자 뒤 배경(body)은 `#241F1C`입니다. 모바일 프레임 바깥 영역에만 씁니다.
- 정의되지 않은 색을 새로 쓸 때는 먼저 이 표에 토큰을 추가합니다.

## 타이포그래피

| 용도 | 글꼴 |
|------|------|
| 본문·UI | Pretendard (jsDelivr), 대체: Malgun Gothic, Apple SD Gothic Neo |
| 영문 장식 (VIP, Recipient 등) | Cormorant Garamond (Google Fonts) |

- 기본 행간은 1.6입니다. 한국어 줄바꿈이 필요한 곳은 `word-break: keep-all`을 씁니다.
- 제목 크기: 메인 제목 25px, 굵기 700~800.

## 모양과 간격

- 카드 모서리: 12~16px, 버튼과 칩은 pill 형태(20~30px).
- 카드 그림자는 `--shadow-card`, 강조는 `--shadow-strong`을 씁니다.
- 기본 여백: 좌우 20px (메인 콘텐츠), 모바일 좌우 최소 16px.

## 모션

- 상자 떠다님(3초), 상자 열기(0.8초), 바운스 안내(2초)를 기본으로 씁니다.
- 모션은 1초 이내를 원칙으로 하고, 반복 애니메이션은 사용자 행동을 방해하지 않아야 합니다.
- 새 애니메이션을 추가할 때는 `prefers-reduced-motion`을 고려합니다. (현재 미적용, `07-open-questions.md` 참고)

## 반응형

- 기준 폭: 모바일 390px, 데스크톱에서는 440px 컨테이너를 가운데 정렬합니다.
- 모바일 전용 규칙은 `@media (max-width: 440px)` 하나로 관리합니다.
- 가로 스크롤은 허용하지 않습니다.

## 아이콘과 이모지

- 이모지는 장식과 감정 표현에만 씁니다. 기능 버튼의 유일한 의미 전달 수단으로 쓰지 않습니다.
- 음악 토글은 SVG 아이콘을 씁니다.
