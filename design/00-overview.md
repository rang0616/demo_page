# 00. 개요

상태: 초안

## 목적

윰댕이 **퇴사와 새로운 진로(대학원) 준비**를 응원받고, **11/18 생일 선물**로 리스파이어랩 양재점 패시브 스트레칭 20회 회원권을 **완전한 서프라이즈**로 받게 하는 것.

## 수신자와 상황

- **수신자**: 윰댕. 페이지에 대해 아무것도 모르는 상태에서 링크를 받습니다.
- **발신자**: 휘님(개발·운영). 중학교 친구가 운영하는 센터에 선물을 준비했습니다.
- **선물 구성**: 회원권 금액이 커서 **퇴사 축하, 진로 응원, 생일 선물을 한 번에 묶은 선물**입니다. 페이지에서 금액과 유효기간은 밝히지 않습니다.

## 핵심 경험

1. 윰댕은 링크를 열고 "선물이 도착했습니다" 안내 화면을 본 뒤, 버튼을 눌러 비밀번호 질문으로 들어갑니다. (ADR-057)
2. 답을 맞히면 선물이 열리고, 바우처(뒷면은 센터 안내), 편지, 예약 안내가 차례로 나타납니다.
3. 마지막에 예약 안내 문구로 마무리됩니다. 문구 기준은 `02-content.md`입니다.

## 톤

- **차분한 편지 + 설레는 이벤트**를 섞습니다. 편지는 조용히 읽히고, 선물을 여는 순간은 두근거리게 합니다.
- 데모의 "쇼핑몰 같은" 느낌(요란한 배지, 과한 그라데이션, 장식 과잉)은 빼고, **아기자기하고 귀여운** 느낌을 목표로 합니다.

## 성공 기준

1. 윰댕이 설명 없이 비밀번호 질문을 이해하고 답을 입력할 수 있습니다.
2. 잠금을 풀면 편지와 바우처가 끊김 없이 읽힙니다.
3. 윰댕의 갤럭시(360px 폭)가 기준이고 휘님의 아이폰 14 Pro(393px 폭)에서도 가로 스크롤 없이 끝까지 같게 동작합니다.
4. 편지 원문이 요청대로 바뀝니다. 휘님이 직접 요청한 변경(ADR-076, ADR-094, ADR-098) 외에는 한 글자도 바뀌지 않습니다.

## 범위

포함:
- 비밀번호 질문으로 여는 잠금 화면
- 선물 도착 안내 화면 (첫 화면, ADR-057)
- 선물 열기 연출 (뚜껑 열림, 폭죽, 효과음: 버튼 뾱, 상자 뿅, 바우처 짜잔, ADR-055, ADR-058)
- 편지, 바우처, 센터 정보, 예약 안내 문구
- GitHub Pages 배포

제외:
- 사진과 영상 (텍스트만)
- 금액, 유효기간 표시
- 날짜 선택 달력과 예약 시스템
- 서버, 로그인, 계정, 다국어
- 틀린 횟수 제한 (요청에 따라 제한 없음)
