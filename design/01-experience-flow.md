# 01. 경험 흐름

상태: 초안 (화면 순서는 제안입니다. 검토 후 확정합니다.)

## 전체 흐름

```
[1. 잠금 화면]
  질문: "우리가 사귀기 시작한 날짜는?"
  입력창 → 확인
     │  틀림: 부드러운 안내 문구 후 다시 입력 (횟수 제한 없음)
     │  맞음: 잠금 해제
     ▼
[2. 선물 열기]
  선물 상자 → 탭 → 열림 연출
     ▼
[3. 바우처]
  패시브 스트레칭 20회 회원권 카드
     ▼
[4. 편지]
  "사랑하는 윰댕에게 ❤️" 편지 원문 (기본 펼침)
     ▼
[5. 센터 안내]
  리스파이어랩 양재점 이름, 주소, 교통, 지도 링크
     ▼
[6. 예약 안내 문구]
  (문구는 `02-content.md`의 예약 안내 문구를 참조)
```

## 화면별 규칙

### 1. 잠금 화면
- 질문 문구와 입력창, 확인 버튼만 둡니다. 다른 정보는 보이지 않습니다.
- 답의 정규화 규칙은 `06-decisions.md` ADR-025를 따릅니다.
- 틀려도 횟수를 세지 않으며, 잠금을 다시 걸지 않습니다. 짧은 격려 문구만 보입니다.
- 힌트는 주지 않습니다. 문구는 아기자기하게, 과한 경고는 없이 씁니다.
- 기본 문구 (Q15 승인 대기, 말투는 ADR-029에 따라 반말):
  - 틀림: "거의 다 왔어! 한 번 더 떠올려 볼래?"
  - 빈 입력: "날짜를 먼저 적어 줘."
  - 입력창 안내(placeholder)는 쓰지 않습니다. 힌트 없이 질문만 보입니다.
- 확인 버튼 라벨은 "열어 보기"입니다. Enter 키로도 제출합니다.
- 입력창은 `autocomplete="off"`, 한국어 키보드를 기본으로 씁니다.
- 확인을 누르면 "열고 있어…" 표시를 보여 줍니다. 복호화에 걸리는 동안 버튼은 잠깁니다.
- 잠금 전에는 편지와 바우처 내용이 화면과 소스 어디에도 평문으로 보이지 않습니다. (`05-architecture.md` 참고)

### 2. 선물 열기
- 상자를 한 번 탭하면 열리고, 열리는 동안 짧은 연출이 나옵니다.
- 상자를 여는 연출은 1초 안쪽으로 끝냅니다.
- 열 때 작고 경쾌한 효과음 하나를 재생합니다. 파일 없이 WebAudio로 합성합니다. 음소거 버튼은 두지 않습니다. (ADR-010, ADR-027)
- 연출은 한 페이지 안에서 화면을 바꿉니다. 이전 화면은 숨기고 다음 화면을 보여 주며, 뒤로 가기는 없습니다.
- 모션 감소 설정(`prefers-reduced-motion`)이 켜져 있으면 연출을 줄이고 바로 바우처를 보여 줍니다.

### 3. 바우처
- 회원권 카드는 `02-content.md` 바우처 표의 항목을 모두 보여 줍니다. 금액과 유효기간은 없습니다. (ADR-005)
- 카드에는 `02-content.md` 바우처 표의 8개 행이 모두 표시됩니다. 값도 그대로 씁니다.

### 4. 편지
- 기본 펼침 상태로 시작합니다. 버튼 라벨은 펼친 상태에서 "접어두기", 접힌 상태에서 "펼쳐보기"입니다.
- 본문은 `02-content.md`의 원문을 그대로 씁니다.

### 5. 센터 안내
- 센터 이름, 주소, 교통 안내, 사전 예약제 안내를 보여 줍니다.
- 주소 복사와 함께 네이버 지도 링크를 둡니다. (ADR-012)
- 복사 성공: "주소를 복사했어!". 복사 실패(인앱 브라우저 등): 주소 글자를 길게 눌러 복사할 수 있게 화면에 선택 가능한 텍스트로 보여 줍니다.

### 6. 예약 안내 문구
- 날짜를 고르는 기능은 없습니다. 문구만 보여 줍니다. (`03-booking.md`)

## 예외 흐름

- 입력창에 빈 값으로 확인을 누르면 빈 입력 안내(위 기본 문구)만 보입니다.
- 새로고침하면 잠금 화면부터 다시 시작합니다. 맞춘 상태는 저장하지 않습니다.
- 자바스크립트가 꺼져 있거나 로드되지 않으면 `<noscript>`에 적힌 "이 페이지는 자바스크립트가 필요해. 브라우저 설정에서 켜 줘." 안내가 보입니다. JS 자체가 실패하면 JS가 안내할 수 없으므로 HTML에 이 문구를 미리 둡니다.
- 암호문 파일을 받지 못하면(네트워크 오류) "잠시 후 다시 열어 줘"를 보여 줍니다. 이 경우는 틀린 답과 구분합니다.
