# 01. 경험 흐름

상태: 초안 (화면 순서는 제안입니다. 검토 후 확정합니다.)

## 전체 흐름

```
[1. 잠금 화면]
  질문: "우리가 사귀기 시작한 날짜는?"
  입력창 → 확인
     │  틀림: 부드러운 안내 문구 후 다시 입력 (횟수 제한 없음)
     │  맞음: 잠금 해제
     ▼
[2. 선물 열기]
  선물 상자 → 탭 → 열림 연출
     ▼
[3. 바우처]
  패시브 스트레칭 20회 회원권 카드
     ▼
[4. 편지]
  "사랑하는 윰댕에게 ❤️" 편지 원문 (기본 펼침)
     ▼
[5. 센터 안내]
  리스파이어랩 양재점 이름, 주소, 교통, 지도 링크
     ▼
[6. 예약 안내 문구]
  "첫 예약은 내가 해줄게! 가능한 날짜를 나에게 말해줘!"
```

## 화면별 규칙

### 1. 잠금 화면
- 질문 문구와 입력창, 확인 버튼만 둡니다. 다른 정보는 보이지 않습니다.
- 답은 공백과 대소문자 차이를 무시합니다. 허용 형식은 `02-content.md`를 따릅니다.
- 틀려도 횟수를 세지 않으며, 잠금을 다시 걸지 않습니다. 짧은 격려 문구만 보입니다.
- 힌트는 주지 않습니다. 문구는 아기자기하게, 과한 경고는 없이 씁니다.
- 잠금 전에는 편지와 바우처 내용이 화면과 소스 어디에도 평문으로 보이지 않습니다. (`05-architecture.md` 참고)

### 2. 선물 열기
- 상자를 한 번 탭하면 열리고, 열리는 동안 짧은 연출이 나옵니다.
- 상자를 여는 연출은 1초 안쪽으로 끝냅니다.
- 소리는 기본적으로 끄고, 켜는 선택지는 두지 않습니다. (`07-open-questions.md` Q4)

### 3. 바우처
- 회원권 카드는 이름과 센터, 횟수(20회)만 보여 줍니다. 금액과 유효기간은 없습니다.
- 바우처 항목(수신자, 사유, 센터, 상품)은 `02-content.md` 값을 그대로 씁니다.

### 4. 편지
- 기본 펼침 상태로 시작합니다. 접고 펼 수 있습니다.
- 본문은 `02-content.md`의 원문을 그대로 씁니다.

### 5. 센터 안내
- 센터 이름, 주소, 교통 안내, 사전 예약제 안내를 보여 줍니다.
- 지도 링크는 제공하지 않습니다. 주소 복사만 둡니다. (Q7)

### 6. 예약 안내 문구
- 날짜를 고르는 기능은 없습니다. 문구만 보여 줍니다. (`03-booking.md`)

## 예외 흐름

- 입력창에 빈 값으로 확인을 누르면 입력하라는 안내만 보입니다.
- 새로고침하면 잠금 화면부터 다시 시작합니다. 맞춘 상태는 저장하지 않습니다.
- 스크립트가 끝까지 로드되지 않으면 "페이지를 다시 열어 주세요" 안내를 보여 줍니다.
