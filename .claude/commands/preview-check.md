`index.html`의 변경 사항을 점검합니다. 이 프로젝트는 빌드가 없으므로 브라우저 확인이 곧 테스트입니다.

점검 순서:

1. `index.html`을 Read로 열어 변경된 부분(CSS 블록, 하단 `<script>`)을 확인합니다.
2. 문법 문제가 의심되면 `node --check`로 인라인 스크립트를 검사할 수 있도록 `<script>` 내용만 임시 파일(스크래치패드)로 추출해 검사합니다.
3. 브라우저에서 `open index.html`로 엽니다. 다음 항목을 체크리스트로 보고합니다.
   - [ ] 콘솔 에러 없음
   - [ ] 390px 폭(모바일)에서 가로 스크롤 없음, 본문 좌우 여백 16px 이상
   - [ ] 1280px 폭(데스크톱)에서 440px 컨테이너가 가운데 정렬됨
   - [ ] 선물 상자 클릭 → 콘페티 → 메인 화면 공개
   - [ ] 편지 접기/펼치기 버튼 동작
   - [ ] BGM 토글 버튼 재생/정지 및 아이콘 상태
   - [ ] 예약 모달: 날짜 선택(지난 날짜 비활성), 월 이동, 시간대 칩 선택, 요약 문구 갱신
   - [ ] 예약 메시지 복사 후 alert 노출
4. 확인하지 못한 항목(예: 실제 기기 사파리, 오디오 재생 여부)은 "미확인"으로 명시합니다.

결과는 체크리스트 형태로 정리하고, 실패 항목이 있으면 원인이 된 줄 번호를 `index.html:줄번호` 형식으로 함께 적습니다. 코드 수정은 사용자가 요청하기 전까지 하지 않습니다.
