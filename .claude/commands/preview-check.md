`src/`의 변경 사항을 점검합니다. 이 프로젝트는 빌드가 없으므로 브라우저 확인이 곧 테스트입니다.

순서:

1. 자동 검사를 먼저 실행합니다.
   - `node --test tests/*.test.mjs` (정규화, 암호 왕복, 페이지 구조)
   - `src/data/letter.enc.json`이 있으면 `node tools/encrypt.mjs --self-test`는 사용자가 직접 실행하도록 안내합니다. (정답 입력이 필요하므로 대신 실행하지 않습니다)
2. `python3 -m http.server -d src`를 백그라운드로 실행하고 `http://localhost:8000`을 엽니다. `file://`로 열면 암호문을 읽을 수 없습니다.
3. 아래 체크리스트를 확인하고 결과를 보고합니다. 확인하지 못한 항목은 "미확인"으로 적습니다.
   - [ ] 콘솔 오류 없음
   - [ ] 360px(갤럭시 S24, 기준)·393px(아이폰 14 Pro)·390px 폭에서 모든 화면에 가로 스크롤이 없음. 두 기기에서 같은 모양으로 나옴 (ADR-083)
   - [ ] 갤럭시: 크롬의 웹사이트 다크 모드를 켜도 색이 뒤집히지 않음. 삼성 인터넷의 웹사이트 다크 테마는 켜고 결과를 기록(뒤집히면 한계로 보고, 설정에서 끌 수 있음). 시스템 글자 크기를 키워도 화면이 깨지지 않음
   - [ ] 360px(갤럭시 S24)에서 바우처 제목과 "20회" 강조, 달력의 줄바꿈이 자연스러움
   - [ ] 아이폰: 입력창을 눌러도 화면이 확대되지 않음. 무음 모드를 끈 상태에서 소리가 나고(무음 모드에서는 소리가 안 나는 것이 정상), 주소 복사가 안 되면 실패 문구가 나옴
   - [ ] 두 기기에서 정답을 입력하고 암호가 3초 안에 풀림
   - [ ] 잠금 화면에 "신원을 확인하겠습니다. / 아래 질문에 답을 해주세요." 두 줄과 "휘와 윰댕이 사귄 날은?" 질문이 보임 (안내는 작게, 질문은 크고 굵게)
   - [ ] 처음에는 안내 화면만 보임. "지금 바로 확인하기"를 누르면 잠금 화면, 새로고침하면 다시 안내 화면부터
   - [ ] 안내 제목이 두 줄("윰댕님❤️!" / "선물🎁이 도착했습니다.")로 보임. 이모지는 스크린리더가 읽지 않음
   - [ ] 안내 화면에서 잠금 화면으로 넘어가면 포커스가 잠금 화면 제목으로 이동해 안내와 질문을 함께 읽음
   - [ ] 모든 버튼(시작, 열어 보기, 다음, 이전 카드 "<", 편지 봉투 "열기", 주소 복사하기)을 누르면 "뾱" 소리가 나고, 상자 버튼은 "뿅"만 남. "네이버 지도로 보기" 링크는 소리가 없음 (실기기에서 확인)
   - [ ] JS가 꺼져 있으면 안내 화면 없이 noscript 문구만 보임
   - [ ] 링크 미리보기(og)와 페이지 제목에 이름이 없고, 미리보기 이미지는 선물 상자 그림임 (카카오톡에 링크를 보내 확인. 옛 로고가 보이면 카카오 공유 디버거로 초기화, ADR-064)
   - [ ] 빈 입력 → "날짜를 먼저 적어 줘."
   - [ ] 틀린 날짜 → 틀림 문구, 입력값 유지
   - [ ] 맞는 날짜 → 선물 상자 화면
   - [ ] 상자를 누르면 폭죽이 터지고 뚜껑 연출 후 바우처 카드 (폭죽은 약 1.8초 뒤 사라지고, 이후 탭이 막히지 않음)
   - [ ] "뿅"(상자를 누를 때)과 "짜잔"(바우처로 넘어갈 때) 두 소리가 겹치지 않고 들림 (실기기에서 확인)
   - [ ] 제목과 Care Type의 "20회"가 짙은 장밋빛과 굵은 글씨로 강조되어 보임(영문 배지는 그대로, ADR-085)
   - [ ] 바우처에 로고와 8개 값이 보임 (영문 라벨이 대문자로 바뀌지 않음). 카드가 로즈골드 테두리와 진주빛 그라데이션의 메탈 느낌이고 반사광이 천천히 지나가며, 모든 글자가 또렷하게 읽힘 (모션 감소 설정에서는 반사광이 움직이지 않음, ADR-071)
   - [ ] 카드 순서는 바우처 → 편지 → 센터 안내 → 예약 안내
   - [ ] 편지 카드(펼친 뒤): 호칭, 본문, 맺음말이 손글씨 글꼴로 보이고(실제 편지로 확인), 문단 안의 줄바꿈이 보존되며 맺음말은 오른쪽 정렬. 가로 줄이 있는 편지지(흰 종이, 세로 여백선 없음, 글이 쓰는 폭이 넓음)에 글이 줄 위에 앉아 있고 긴 편지에서도 줄과 글이 어긋나지 않음 (실제 편지, 갤럭시와 아이폰에서 확인, ADR-070, ADR-083)
   - [ ] 320px 폭에서도 편지·센터·예약 카드에서 페이지가 가로로 넘치지 않음(예약 카드의 두 줄 문구와 💌 줄바꿈 포함. 달력 안의 옆으로 넘기기는 의도된 동작)
   - [ ] 편지는 처음에 닫힌 봉투이고 봉인 자리에 둥근 "열기" 버튼이 있음. "다음" 버튼은 아직 없음. 봉투 위에 "편지가 도착했습니다!"가 보임. 누르면 제목이 사라지고 덮개가 열리며 종이가 올라온 뒤(약 0.8초, 너무 길게 느껴지지 않는지 아이폰에서 확인) 봉투가 사라지며 편지와 "다음" 버튼이 나타나고 포커스가 편지로 감 (모션 감소 설정에서는 바로 편지)
   - [ ] 카드는 내용 프레임(바우처는 메탈 카드)과 그 아래 별도의 "다음" 버튼으로 나뉘어 보이고(예약 카드는 "다음" 버튼이 없음), "다음" 버튼은 프레임과 같은 폭이며 프레임 아래 16px에 있음. 이전 버튼과 함께 한 덩어리로 나타남(ADR-081)
   - [ ] 편지 카드는 봉투 상태에서도 흰 프레임 없이 제목과 봉투가 배경 위에 놓이고, 편지를 열면 편지지(흰색)만 보임. 흰 종이가 배경과 구분되어 보임(종이 그림자와 둥근 모서리, ADR-086). 열릴 때 화면이 튀거나 높이가 어색하게 바뀌지 않음(아이폰 14 Pro, 갤럭시). 카드에서 Tab을 누르면 이전 버튼이 먼저 잡히는 순서가 자연스러움
   - [ ] 이전 버튼("<")에 마우스를 올리면 바탕이 연한 분홍으로 바뀌고, 누르는 동안(폰과 마우스 모두) 분홍색이 되며 살짝 작아졌다가 돌아옴. 분홍 상태와 크기 변화 중에도 Tab 포커스 윤곽이 또렷하고, 모션 감소 설정에서는 서서히가 아니라 즉시 바뀜 (ADR-086)
   - [ ] 왼쪽 위 "<" 버튼: 바우처에서는 안 보이고, 편지·센터·예약 카드에서 보임(카드와 함께 나타남, 따로 늦게 나타나거나 깜빡이지 않음). 누르면 한 장 앞 카드로 가고 바우처까지만 감(상자·잠금 화면으로 안 감). 다시 편지로 오면 열린 채로 남아 있음. 카드 위쪽 글과 겹치지 않음
   - [ ] 센터 안내 카드: 맨 위에 센터 이름, 그 아래 로고, 이어서 사전 예약제 안내, 주소, 교통, 버튼 순서는 "네이버 지도로 보기"가 위, "주소 복사하기"가 아래로 보이고 소개 문구 3개는 없으며 "다음" 버튼이 있음 (ADR-068, ADR-084)
   - [ ] "네이버 지도로 보기"가 네이버 초록색 버튼이고 앞에 "N" 아이콘이 있으며 글자가 또렷하게 읽힘. 누르면 새 탭(또는 지도 앱)으로 열림 (ADR-068)
   - [ ] 예약 안내 카드(마지막): "첫 예약 안내" 라벨과 본문("첫 예약은 내가 해줄게! / 가능한 날짜를 나에게 말해줘! 💌"), 그 아래 2026년 10월 달력이 있고 옆으로 밀면 11월이 나옴(한 번에 한 달만 보임. 맨 왼쪽·맨 오른쪽으로 당겨도 다른 달이 같이 보이지 않음, 아래 점이 따라 바뀜). 토요일 날짜와 "토"는 파란색, 일요일 날짜와 "일"은 빨간색이고 지난 토·일은 옅은 파랑·빨강(ADR-079). 11월 18일에 하트가 있고(320px에서도 숫자와 겹치지 않음) 오늘 이전 날짜의 숫자가 옅게 보임(오늘부터는 보통 색). 윰댕이 아래 점만 보고 11월이 있다는 것을 알아챌 수 있는지 눈으로 확인(밀어 보게 하는 단서가 부족하면 알려 주기). 날짜를 눌러도 아무 일도 없고 입력창이 없음. 달력 아래 점을 누르면 그 달로 부드럽게 넘어가고(손가락으로 밀어도 됨) 현재 달의 점이 진하게 바뀜, 점의 터치 영역이 충분함(ADR-077). 10/1은 목요일, 11/1은 일요일. 흐름이 여기서 끝나고 더 넘어가지 않음 (ADR-069)
   - [ ] 처음부터 끝까지 한 번에: 안내 → 잠금 → 상자 → 바우처 → 편지 → 센터 → 예약
   - [ ] 선물 상자 화면의 안내 문구가 "상자를 눌러 선물을 확인하세요."임 (ADR-074)
   - [ ] 편지의 맨 아래 맺음말이 영어 문장이 아니라 휘님의 서명으로 보임 (지금은 화면 코드가 서명을 대신 보여 줌. 암호문을 다시 만들고 상수를 지운 뒤에도 서명이 한 번만 보이는지 실제 정답으로 확인, ADR-076의 되돌리는 순서)
   - [ ] "주소 복사하기"를 누르면 "주소를 복사했어!"가 나오고 붙여넣기 하면 주소가 들어감 (카카오톡 인앱 브라우저에서도 확인). 복사가 안 되면 "복사가 안 됐어. 주소를 길게 눌러서 복사해 줘."가 나오고 주소를 길게 눌러 선택할 수 있음
   - [ ] "네이버 지도로 보기"가 새 탭(또는 지도 앱)으로 열리고 주소가 검색됨
   - [ ] 카드는 "다음" 버튼으로만 넘어가고, 카드의 빈 곳을 눌러도 반응이 없음. 마지막 카드에서 멈춤
   - [ ] 상자나 카드를 연달아 눌러도 카드를 건너뛰지 않음
   - [ ] 모션 감소 설정에서 뚜껑 연출과 폭죽 없이 바로 바우처 (소리는 유지)
   - [ ] 카드가 나타날 때 "빠밤"(두 번 통통 튐)이 보이고 "짜잔" 박자와 맞음 (실기기)
   - [ ] "다음"으로 넘어간 카드도 같은 연출을 하고, 연출 중에도 360px·393px·390px 폭에서 가로 스크롤이 생기지 않음
   - [ ] 모션 감소 설정에서는 카드가 연출 없이 바로 보임
   - [ ] 로고가 최대 300px로 선명하게 보임 (아이폰 14 Pro와 갤럭시의 고밀도 화면). 옅은 베이지 배경의 로고가 흰 카드 위에서 어색하지 않은지 눈으로 확인
   - [ ] 암호문 파일이 없을 때 → "잠시 후 다시 열어 줘.", 입력값 유지
   - [ ] 소스 보기에서 정답과 평문 편지가 없음
