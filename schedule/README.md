## 진행률 계산 규칙

- **일별 진행률** = 그날 목표 작업 중 완료한 수 ÷ 그날 목표 작업 수.
- **PR별 진행률** = 해당 단위의 완료 작업 수 ÷ 전체 작업 수.
- **전체 진행률** = Σ(PR별 진행률 × 가중치) ÷ 100. 가중치는 위 표의 값입니다.
- 작업 하나는 "완료 조건을 충족하고 확인까지 끝난 것"만 완료로 셉니다. 확인하지 못한 것은 완료가 아닙니다.
- 진행률 막대는 10칸입니다. 10%당 1칸이며 반올림합니다.

## 갱신 방법

1. 작업을 마치면 해당 일별 파일의 체크박스를 `[x]`로 바꿉니다.
2. 일별 진행률과 이 문서의 표(날짜별, PR별, 전체)를 같은 값으로 고칩니다.
3. 계획이 바뀌면 일별 파일의 "변경 이력"에 이유와 함께 적습니다.
